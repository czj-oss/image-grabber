WHY IMAGEGRAB

把分散的商品图片，整理成一次可完成的下载任务

详情页图片常常隐藏在懒加载属性、响应式图片或背景图中。图提取会集中扫描并去除重复的小图标。

你可以在独立画廊中预览结果，选择真正需要的图片，再批量保存到本地。

CORE FEATURES

从提取到下载，保持清晰可控

01

一键提取

自动扫描商品图片并兼容常见懒加载属性。

02

智能过滤

过滤 logo、图标、占位图和过小图片。

03

集中预览

在新页面以网格方式查看提取结果和图片尺寸。

04

自由勾选

支持全选、反选和按需下载，减少重复操作。

05

统一 PNG

下载时尝试将 JPG、WebP 等格式转换为 PNG。

06

批量下载

按序号生成文件名，保存到浏览器默认下载目录。

INSTALLATION

四步加载扩展

  1. 01

    下载并解压

    将插件项目文件夹保存到本地，不要删除其中的 manifest.json。

  2. 02

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 并回车。

  3. 03

    打开开发者模式

    点击扩展管理页面右上角的“开发者模式”开关。

  4. 04

    加载已解压的扩展程序

    点击按钮，选择包含 manifest.json 的项目根目录。
