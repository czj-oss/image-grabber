# Lumen Reader

课程实习项目：支持 TXT、EPUB、本地书架、目录切换和阅读进度恢复的 Electron 桌面阅读器。

## 启动

在本目录执行：

```powershell
npm install
npm run dev
```

如果只想验证构建：

```powershell
npm run build
npm start
```

## 截图建议

考核表单的“03 文档截图”可以截取 `PRD.md`、`TECH_DESIGN.md`、`AGENTS.md` 在编辑器中的内容。

“04 应用截图”建议准备三张：

1. 默认示例书打开，能看到书架、正文和目录。
2. 导入 TXT 后，点击目录切换章节。
3. 导入 EPUB 后，显示 EPUB 标识和目录。

应用窗口可以使用 Windows 截图工具 `Win + Shift + S`，框选整个阅读器窗口。
