# AGENTS.md

## 项目概述

这是蔡子靖的个人展示网站，使用 React、TypeScript 和 Vite 构建。网站包含个人介绍、技能、项目、学习笔记和联系入口，视觉方向为深色星空主题。

## 开发规范

- 优先使用 TypeScript，避免使用 `any`。
- 组件职责保持清晰，页面展示数据使用明确的类型定义。
- 所有可交互按钮使用语义化 `button` 或 `a` 元素。
- 图标优先使用 `lucide-react`，不要手写重复 SVG。
- 颜色、边框、间距和背景尽量使用 `styles.css` 中的统一规则。
- 所有外部链接使用 `target="_blank"` 和 `rel="noreferrer"`。
- 不在客户端写入密码、Token 或其他敏感信息。

## 测试要求

每次修改后执行：

```bash
npm run build
```

浏览器测试至少覆盖：

- 桌面宽度下首屏、导航、项目链接和邮箱复制。
- 375px 手机宽度下菜单展开、内容换行和无横向滚动。
- 开启减少动态效果设置后，星空动画不会持续消耗资源。
- 浏览器控制台没有未处理的错误。

## 设计要求

- 保持深色背景与蓝色强调色。
- 不使用大面积装饰性卡片堆叠。
- 文案清楚、具体，避免空泛的营销表达。
- 保持至少 AA 级别的文字对比度。

## 部署要求

- Vercel 或 Cloudflare Pages 的根目录必须设置为 `personal-site`。
- 构建命令为 `npm run build`。
- 输出目录为 `dist`。
- 不要把 `node_modules` 或环境密钥提交到 Git。
