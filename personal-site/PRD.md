# 个人展示网站 PRD

## 1. 项目概述

这是蔡子靖的个人展示网站，用于展示个人介绍、技能、项目实践和学习笔记。网站面向招聘者、课程老师、同学和潜在合作伙伴，重点表达“持续学习、能把想法做成可用产品”的个人形象。

## 2. 目标

- 在首屏说明个人方向和当前关注领域。
- 通过项目列表展示实际开发能力，而不是只展示技能名称。
- 通过笔记区记录 AI 编程、前端开发和 Bug 排查过程。
- 提供 GitHub、邮箱等清晰的联系入口。
- 在桌面、平板和手机上保持可读、可操作和无横向滚动。

## 3. 核心功能

### 3.1 首页 Hero

- 显示姓名、方向和一句话介绍。
- 提供“查看项目”和“了解工作方式”入口。
- 使用 Canvas 星空背景，形成明确的个人视觉识别。

### 3.2 个人介绍

- 展示学习方向、工作方式和个人事实信息。
- 使用简短段落，避免大段自我描述。

### 3.3 技能展示

- 按 Frontend、AI Coding、Product、Tooling 分类展示。
- 每个分类包含技能名称和具体工具。

### 3.4 项目展示

- 展示项目名称、项目类型、简介、技术标签和链接。
- 项目行支持悬停反馈。

### 3.5 博客和笔记

- 展示笔记标题、日期、分类和摘要。
- 当前版本使用静态内容，后续可改为 Markdown 文件自动生成。

### 3.6 联系

- 邮箱按钮支持复制邮箱。
- 提供 GitHub 链接和返回顶部入口。

## 4. 设计要求

- 深色主题，背景色接近 `#080c18`。
- 星空使用 Canvas 粒子绘制，移动端减少粒子数量。
- 主色使用浅蓝色，辅助色使用低饱和蓝紫色。
- 使用充足留白、细边框和轻量动效。
- 导航栏吸顶并使用毛玻璃背景。
- 手机端导航收起为菜单按钮。
- 375px 宽度下不出现横向滚动。
- 支持 `prefers-reduced-motion`，降低动效。
- 文字与背景保持足够对比度，交互控件支持键盘操作。

## 5. 非功能要求

- 页面首屏加载后不依赖后端接口。
- 不上传用户信息，不收集访问者隐私数据。
- 使用相对路径，保证 Vercel 和 Cloudflare Pages 可部署。
- `npm run build` 必须成功。

## 6. 本期不做

- 不做登录系统。
- 不做真实博客后台。
- 不做数据库。
- 不做在线留言后端。
